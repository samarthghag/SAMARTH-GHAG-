# Samarth Ghag Portfolio Hub

A modern, animated portfolio website for Samarth Ghag, showcasing skills in AI, cybersecurity, and full-stack development.

---

## Features
- Animated hero section with profile image and tech highlights
- Resume download button linking to Google Drive
- Logo displayed next to the site title
- Built with React, TypeScript, Tailwind CSS, shadcn-ui, and Vite

---

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
